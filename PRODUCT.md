# NEXTGUARD AI — Product Differentiation

NEXTGUARD AI is an intelligence, correlation, visualization, and investigation layer. It complements Suricata, Zeek, Splunk, OpenVAS, and Security Onion rather than replacing them.

## Differentiators mapped to the implementation

1. **Unified security visibility** — ingestion, asset intelligence, graph, vulnerabilities, incidents, and monitoring APIs connect telemetry across sources.
2. **Interactive 3D network intelligence** — the React twin visualizes aggregated devices, services, relationships, suspicious routes, critical assets, and live updates.
3. **Explainable threat detection** — findings preserve `observed_evidence`, `inferred_risk`, confidence, reasoning, related alerts, and recommendations.
4. **Context-aware analysis** — baselines, device context, destinations, services, vulnerabilities, and correlated events are combined before escalation.
5. **Proactive attack-path intelligence** — `/api/attack-paths` derives possible entry-to-critical routes and supports what-if remediation analysis.
6. **Unified investigation workflow** — cases, timelines, evidence, reports, remediation approvals, and verification snapshots are connected.
7. **Training and evaluation** — PCAP replay, scripted scenarios, ground-truth comparison, multi-run history, and `/api/evaluation` provide a repeatable lab workflow.

The product's trust boundary is intentional: source tools provide observations; NEXTGUARD AI adds correlation and inferred intelligence; analysts authorize any infrastructure-changing action.
